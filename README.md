# SAT_RC_RRC
Preparing CNF files for SAT solvers. Used to compute the rectangle covering and refined rectangle covering bound.

## Usage:
The given files can be used to compute the cnf, that then can be solved by kissat for example. We used kissat on our server, but pysat supports it too.
We used sage to compute the positive determinant pairs. The code is not provided and needs SageMath to run.
